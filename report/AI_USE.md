# Use of AI tools

This is the same disclosure as the "Use of AI Tools" section of `report.pdf`.

Microsoft Copilot and Claude were used to explain Apache Flink concepts, debug build and
configuration problems and review code. Assistance of AI coding agent (Claude Code) was used to
implement: the event classification and watermark changes, the producer, the reference and
validator, the experiment scripts and the dashboard. We reviewed and verified the code, re-ran the
validation and the laptop experiments ourselves.
