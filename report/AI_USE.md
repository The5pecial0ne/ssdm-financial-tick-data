# Use of AI tools

This is the same disclosure as the "Use of AI Tools" section of `report.pdf`.

Microsoft Copilot and Claude were used to explain Apache Flink concepts, debug build and
configuration problems and review code. In November an AI coding agent (Claude Code) implemented
most of the rework through reviewed pull requests: the event classification and watermark changes,
the producer, the reference and validator, the Docker setup, the experiment scripts and the
dashboard. With the course teacher's permission, Claude also drafted the report from our earlier
draft and the measured results in this repository. We reviewed the code, re-ran the validation and
all experiments ourselves, checked every number in the report against the result files, and take
responsibility for the submitted code and text.
